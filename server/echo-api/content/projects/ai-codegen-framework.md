# AI Code Generation Framework (Trustt)
aliases: codegen, cursor rules, ai framework, velocity

**Pitch:** Cursor IDE rule system that standardizes AI-assisted Angular development across the team.
**Status:** Live — adopted as the team standard at Trustt
**Stack:** Cursor IDE, Angular, TypeScript, SCSS

## The problem
AI coding tools make individuals faster but teams inconsistent — every engineer
prompts differently and gets different-shaped code. This framework turns AI
assistance into a repeatable team process.

## How it works
- A **Cursor IDE rule system** (.cursor rules) encoding a 10-phase AI-assisted
  development workflow, including an 8-step feature registration flow.
- Reusable Angular base component guides and SCSS pattern libraries the AI is
  steered toward, so generated code lands on team conventions.
- Adopted as the standard across the 5-member frontend team.

## The result
Roughly **35% faster feature delivery** — measured on real team output, not a demo.
This is the system behind that number on the resume.

## Why it's interesting
Most "AI velocity" claims are personal anecdotes. This one is a process artifact a
team actually adopted, on a production fintech codebase, with the migration to
Angular 19/20 happening at the same time.
